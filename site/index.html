Run the calculator

git clone https://github.com/SanjaySrivatsa5172/AI-MEDICAL-INFORMATION-STANDARDS-AMIS-.git
cd AI-MEDICAL-INFORMATION-STANDARDS-AMIS-
git checkout cursor/amis-web-calculator-0fb7
python3 -m pip install -r implementation/web/requirements.txt
python3 -m implementation.web.app

Then open http://127.0.0.1:8765. Docker: docker build -t amis-calculator . && docker run -p 8765:8765 amis-calculator

This instrument evaluates epistemic claims. It does not diagnose, dose, or prescribe. Therapeutic decisions require a qualified physician (AMIS Standard 5). It is a deterministic heuristic, not a licensed psychometric scale.
