# A multi-agent large language model framework for structured clinical interviewing and psychiatric screening: a proof-of-concept

**Kamaleddin MA, Mirjalili M, Barzegar R, Trung Le N, Visram A, Gholami Nezhad F, Rueda A, Teferra BG, Monson C, Glatard T, Krishnan S, Sharma D, Mulsant B, Bhat V** — *Translational Psychiatry* (2026)

> [!note] Clinical relevance
> Proof-of-concept multi-agent LLM framework (Questioner, Evaluator, Navigator, Diagnoser agents) for protocolized structured psychiatric interviewing and module-level screening (St. Michael's Hospital / CAMH / University of Toronto; senior authors Mulsant, Bhat). In scope via the protocol's explicit 'psychiatric / suicidal-crisis / behavioral-health chatbot safety' branch: the system is designed to 'identify safety-related RED FLAGS and trigger ESCALATION,' and its central safety evaluation is a 2000-sentence SUICIDAL-IDEATION red-flag benchmark stratified by explicit/implicit and active/passive ideation, on which the classifier achieved 93.9% accuracy, 94.2% sensitivity, 93.6% specificity. (Broader framework: 1350 simulated interviews across 15 neuropsychiatric modules, 87.8% concordance with rule-based expected outcomes [sensitivity 88.9%, specificity 86.7%]; F2 88.5% vs single-pass-LLM 49.5% / rule-based 61.9%; PII/PHI redaction before model processing; clinician-supervised use.) Relevant via emergency-relevance (acute suicidal-crisis red-flag recognition + escalation) + AI-safety FAILURE-MODE (missed-red-flag / escalation sensitivity-specificity), with a partial patient-facing element (the agent administers interview modules and interprets patient free-text responses). Ancillary, design_overlap FALSE: a clinician-supervised structured-interview/screening framework whose acute-crisis content is ONE red-flag-detection module -- a suicidal-ideation red-flag-sensitivity methods cousin, NOT the protocol's patient-facing, physician-adjudicated, harm-weighted emergency-triage design.
