# Suicide-Related Responses From AI Chatbots Through Application Programming Interfaces and Consumer-Facing Apps: Observational Cross-Sectional Comparative Study

**Cantor J, Huang E, Zhang LA, Salas A, Zhang F, Burnett A, Lohn A, Pataranutaporn P, Rader B, Yu H, McBain RK** — *Journal of Medical Internet Research* (2026)

> [!note] Clinical relevance
> RAND Corporation / Harvard observational cross-sectional comparative study of PATIENT-FACING consumer AI chatbots in SUICIDAL CRISIS -- a time-critical crisis-response failure mode in the psychiatric-emergency domain (same in-scope territory as the standing Weilnhammer emergency-psychiatric-triage alert, SIM-VAIL, and the Pichowicz escalating-suicide-risk entry). Design: 5 widely used consumer models (ChatGPT, Claude, Gemini, Grok, Llama) answered 30 clinician-vetted suicide-related prompts spanning 5 clinician-assigned risk levels, each submitted 100x through BOTH the public consumer UI and direct API access (30,000 responses), scored by a blinded GPT-4o-mini classifier validated against human coding (289/300, 96.3% agreement, Cohen kappa=0.89). Findings: 69.8% of responses were 'direct'; direct answering was far MORE common via API than via the consumer UI (77.4% vs 62.2%; mixed-effects UI odds ratio 0.09, 95% CI 0.08-0.10), and the gap was widest at the highest acuity -- for VERY-HIGH-RISK prompts only 4.6% of UI responses were direct vs 24.8% via API, and for high-risk prompts 48.4% UI vs 80.1% API (Gemini was the partial exception, slightly higher direct rate via UI). Bears on the protocol's patient-facing crisis-safety dimension: safety guardrails observed in a consumer interface DO NOT generalize to API access or third-party apps built on the same models, so a UI-only evaluation can overstate real-world safety. design_overlap FALSE and ancillary: a suicide-prompt direct-vs-deflect access-mode safety audit (LLM-classifier-scored) rather than the protocol's physician-authored dual-register harm-weighted emergency-triage-disposition design. NOT auto-alerted: an important harm/safety finding that REINFORCES (does not overturn) the protocol's premise that patient-facing AI crisis safeguards are inconsistent, with no regulatory action or retraction, and it does not match the protocol's full emergency-triage design at the urgent-alert threshold.
